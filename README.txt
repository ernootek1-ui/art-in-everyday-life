ART IN EVERYDAY LIFE — WEBSITE PROJECT
======================================

FILES
-----
index.html  Main website structure and educational content
style.css   Colors, layout, responsive design, and visual styling
script.js   Navigation, category filters, learning popups, and quiz

HOW TO OPEN THE WEBSITE
-----------------------
1. Download and extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html.
4. The website should open in your default browser.

HOW TO EDIT THE WEBSITE
-----------------------
1. Install Visual Studio Code (optional but recommended).
2. In VS Code, choose File > Open Folder and select this project folder.
3. Edit index.html to change headings, paragraphs, categories, or artist information.
4. Edit style.css to change colors, fonts, spacing, and image choices.
5. Edit script.js to change the quiz questions or interactive behavior.
6. Save your changes, then refresh the browser.

HOW TO CHANGE THE COLORS
------------------------
At the top of style.css, edit the variables inside :root:
--ink, --cream, --orange, --yellow, --blue, --pink, and --green.

HOW TO CHANGE THE PHOTOS
------------------------
Search in style.css for the image class names such as .hero-photo,
.image-fashion, .image-architecture, .image-food, and .artist-one.
Replace the URL inside background-image or url(...) with a direct image URL.
The current photos are loaded from Unsplash, so an internet connection is
needed to display them. Google Fonts also loads online.

HOW TO PUBLISH FOR FREE WITH GITHUB PAGES
-----------------------------------------
1. Sign in to GitHub and create a new public repository.
2. Upload index.html, style.css, and script.js to the repository root.
3. Open the repository's Settings.
4. Select Pages from the left menu.
5. Under Build and deployment, choose Deploy from a branch.
6. Select the main branch and /(root), then click Save.
7. Wait for GitHub Pages to publish your website. Open the URL shown there.

EDUCATIONAL CONTENT
-------------------
The site introduces art in fashion, architecture, food presentation,
traditional crafts, nature, and interior spaces. It includes a short quiz.
Review the artist descriptions and adapt the lesson content to match your
teacher's instructions or curriculum before submitting.
